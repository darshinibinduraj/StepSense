# StepSense

StepSense is an interactive mobile app project focused on analyzing labeled movement
recordings, gathering relevant research context, and supporting evidence-grounded
reporting about freezing-of-gait patterns.

## Disclaimer

This is a **research prototype, not a medical device**. It is not clinically validated.
The current model detects **possible freezing episodes** in replayed recordings; it does
not predict falls and does not prevent falls.

## Setup

1. Create and activate a Python 3.11+ virtual environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run a quick module compile check:

   ```bash
   python3 -m compileall stepsense scripts
   ```

## Dataset download and preparation

Reference dataset (Daphnet Freezing of Gait):
<https://archive.ics.uci.edu/dataset/245/daphnet+freezing+of+gait>

Prepare a single CSV/TSV file with:

- participant identifier column (`subject`, `participant`, `participant_id`, `person`, or `id`)
- label column (`label`, `annotation`, `class`, or `target`)
- numeric wearable sensor columns including ankle channels (`ankle*`)
- optional time column (`time`, `timestamp`, or `t`)

Current preprocessing behavior:

- windows are 2 s (128 samples) with 1 s step
- windows with >50% of label `0` are dropped
- a window is freezing when >=25% of labels are `2`

### Build `data/daphnet.csv` from raw Daphnet txt files

If you have raw files such as `data/S01R01.txt`, build the consolidated CSV with:

```bash
python3 scripts/build_daphnet_csv.py --input-dir data --output data/daphnet.csv
```

This keeps raw files untouched and writes:
`subject,time,ankle_hori_fwd_accel,ankle_vertical,ankle_lateral,label`

## Train and evaluate

```bash
python3 scripts/train.py \
  --dataset /path/to/daphnet.csv \
  --model-output models/model.joblib \
  --eval-output models/eval_results.json
```

Outputs:

- `models/eval_results.json`
- `models/model.joblib`

Training includes:

- LOSO evaluation for Random Forest and threshold baseline
- skipped held-out participants list when they have no freezing windows
- final demo model trained on all participants except one held-out participant with freezing episodes

## Replay CLI check

```bash
python3 scripts/replay_cli.py \
  --dataset /path/to/daphnet.csv \
  --model models/model.joblib
```

## Run the Streamlit app

```bash
streamlit run app.py
```

App behavior includes:

- sidebar controls for recording participant, playback speed, detection threshold, consecutive windows, LLM provider
- live ankle-signal chart and freezing probability trace
- shaded ground-truth freezing regions labeled as evaluation-only
- cue playback and caregiver alert card when an event fires
- agent activity log and episode log table
- evaluation tab showing LOSO metrics and skipped participants

## Environment

Copy `.env.example` to `.env` and set:

- `LLM_PROVIDER=mock|openai|anthropic`

Default is `mock` for deterministic, no-key local runs.

## Limitations

- Research prototype only; not clinically validated.
- Does not diagnose disease and does not predict or prevent falls.
- Built for replayed wearable signals (ankle, thigh, trunk); phone-only input is not validated.
- Alert language is intentionally hedged ("possible freezing episode").
- Metrics shown should come from held-out evaluation output files generated by training.
